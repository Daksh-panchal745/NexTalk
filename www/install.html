Install NexTalk

Apne phone par NexTalk ko ek app ki tarah install karo —
fast, full-screen, notifications ke saath.

  1. 1
    Google Chrome me kholoYe page Chrome browser me khula hona chahiye (koi aur browser nahi).
  2. 2
    Neeche "Open NexTalk" dabaoApp khul jayegi. Chrome khud "Install app / Add to Home screen" ka pop-up dikhayega.
  3. 3
    Pop-up na dikhe toChrome ke upar-right ⋮ menu → "Install app" ya "Add to Home screen" → Install.
  4. 4
    Home screen se kholoAb NexTalk ka icon home screen par hai — wahi se kholo, notifications ALLOW karo.
  1. 1
    Safari me kholoiPhone par ye page Safari me khula hona chahiye (Chrome se install nahi hota).
  2. 2
    Neeche "Open NexTalk" dabaoApp khul jayegi — ab Safari ke neeche Share button (⬆︎ wala box) dabao.
  3. 3
    "Add to Home Screen" chunoList me thoda neeche scroll karo → Add to Home Screen → upar-right Add.
  4. 4
    Home screen se kholoNexTalk icon se app full-screen khulegi. Notifications ke liye app ke andar ENABLE dabao (iOS 16.4+).
